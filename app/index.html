Invoice Workspace

Help

Ask in the chat

  • “Check the new invoices”: reads each invoice, applies the confirmed rules and marks where it found things.
  • “Propose rules from the guidelines”: suggests rules with their source page and where to look.
  • “Suggest improvements”: looks at your corrections and proposes clearer descriptions. You approve them under Rules and types.
  • “Run the test invoices”: checks your test invoices again and compares with your confirmed answers.
  • “Switch to project …” or “Start a new project”.

On this page

Add invoices, review and correct results, approve proposals, edit descriptions and rules, see the history, and choose models under Assistant settings.

First-time setup

  1. Install Python 3.10 or newer, and Claude Code (desktop app) or Codex.
  2. Open this folder in the app and ask: “Set this up”.
  3. Ask: “Open the workspace”, or double-click start-workspace in the folder.
  4. Choose a project at the top, or create one (you can start from a colleague’s setup file).
  5. Codex only: trust this folder when Codex asks, so it uses the assistant settings.

The full guide is in README.md in this folder.
