    Help

    Ask in the chat

    • “Check the new invoices” reads each invoice, applies the confirmed rules and marks the evidence.
    • “Propose rules from the guidelines” suggests rules, cites the source page and explains where to look.
    • “Suggest improvements” uses your corrections to propose clearer descriptions. Review them in the Project setup Inbox.
    • Use “Switch to project …” or “Start a new project” to manage projects from the chat.

    Check a specific invoice

    Open the invoice, choose Copy check request and paste the request into your project chat. For one finding, use its Copy question action. Project and invoice IDs travel with the request.

    Use the workspace

    Use Invoices to add invoices, review findings and correct results. Choose an outcome at the top of a rule finding and enter your reason, or use Edit reason to explain the existing decision. On a checked invoice, Export offers the marked PDF, CSV and copyable results.

    Under Project setup, add funder guidelines in Project details, review proposals in the Inbox and edit descriptions and rules. In Settings → Export, you can also download workbooks, setup files and selected history entries, or copy a confirmed spreadsheet row. Open History to see project activity or Assistant settings to choose models.

    First-time setup

    1. Sign in to Claude Code or Codex on this computer.
    2. Open this folder in the app and ask “Set this up”. The assistant installs Python and the required tools in the workspace folder.
    3. Ask “Open the workspace”, or double-click start-workspace in the folder.
    4. Choose a project at the top, or create one. Choose Template project to start with the AEXCID invoice types, fields to extract and proposed rules.
    5. If you use Codex, trust this folder when prompted so Codex uses the assistant settings.

    The full guide is in README.md in this folder.
